### Task 2: World-status SessionStart hook

**Files:** Create `.claude/hooks/world-status.sh`, `.claude/hooks/world-status.test.sh`; modify `.claude/settings.json` (`hooks.SessionStart`).

**Interfaces:** Produces the hook output format (plain text, ≤ ~10 lines) that `agent/README.md` documents.

- [ ] **Step 1: Test first** — `world-status.test.sh` puts a stub `gh` first in `PATH` and asserts:
  - stub returns canned JSON → output contains `branch:`, `issues:`, `PRs:`, `pipeline:`; exit 0;
  - stub exits 1 (offline/unauthenticated) → output has the `branch:` line and no error text; exit 0;
  - `gh` missing from `PATH` → same as offline;
  - total runtime < 10 s with a stub that sleeps 30 s (the script's own per-call timeout kills it).
Run it: FAIL (script missing).
- [ ] **Step 2: Script** (bash, `set -u`, never `set -e`):
```bash
#!/usr/bin/env bash
# SessionStart hook: a short "state of the world" added to Claude's context. Never fails, never blocks.
set -u
cd "${CLAUDE_PROJECT_DIR:-.}" 2>/dev/null || exit 0
t() { perl -e 'alarm shift; exec @ARGV' 5 "$@" 2>/dev/null; }  # portable 5 s timeout (macOS has no `timeout`)
echo "World status ($(date -u +%F)):"
echo "- branch: $(git branch --show-current 2>/dev/null || echo '?')"
command -v gh >/dev/null || exit 0
issues=$(t gh issue list --state open --limit 10 --json number,title -q '.[] | "#\(.number) \(.title)"') || exit 0
prs=$(t gh pr list --state open --limit 10 --json number,title -q '.[] | "#\(.number) \(.title)"') || exit 0
run=$(t gh run list --workflow pitwall-pipeline.yml --limit 1 --json conclusion,status,createdAt -q '.[0] | "\(.status)/\(.conclusion // "-") \(.createdAt[:10])"') || run="?"
echo "- issues: ${issues:-none}" | paste -sd ';' -
echo "- PRs: ${prs:-none}" | paste -sd ';' -
echo "- pipeline (pitwall, last run): ${run:-none}"
exit 0
```
- [ ] **Step 3:** register in `.claude/settings.json`:
```json
"hooks": { "SessionStart": [ { "matcher": "startup|resume", "hooks": [ { "type": "command", "command": "\"$CLAUDE_PROJECT_DIR/.claude/hooks/world-status.sh\"", "timeout": 20 } ] } ] }
```
- [ ] **Step 4:** run the test → all pass; run the script for real and read the output; `jq . .claude/settings.json` parses.
- [ ] **Step 5: Commit** `feat(agent): world-status SessionStart hook with regression test`.

### Task 3: `ship` skill

**Files:** Create `.claude/skills/ship/SKILL.md`.

- [ ] **Step 1: Write the skill** — frontmatter `name: ship`, `description:` "Take the current work branch from pushed commits to merged: PR into dev with Closes #n, CI, pr-reviewer, fixes, squash merge, issue closed, branch cleaned. Use when a planned change is committed and verified and should land in dev." Steps with bash blocks:
  1. Preconditions: branch matches `^(feat|fix|docs|refactor|test|chore|ci|infra)/[0-9]+-`; issue number from the branch; working tree clean; local checks green (`make lint`/`make test` in touched projects, link check if docs moved).
  2. `git push -u origin HEAD`; `gh pr create --base dev` with `Closes #$ISSUE` as the first body line and the attribution line.
  3. **Link check before merge:** `gh pr view --json closingIssuesReferences` must contain `$ISSUE`; if not, edit the body and re-check.
  4. CI: use the app's PR status (`get_status`) — never poll in a loop; if checks are pending, end the turn and resume on the CI event or when Tomas says so.
  5. Non-trivial change → `pr-reviewer` agent on the branch; re-grade findings by effect; fix Critical/Important with a failing check first; ledger rulings; push.
  6. Merge: `gh pr merge <pr> --squash --delete-branch` (CLAUDE.md merge authority). `gh` may leave local `dev` behind: `git switch dev && git pull --ff-only`.
  7. Issue: `gh issue view $ISSUE --json state`; if OPEN, close with `--comment "Delivered by #<pr>"` (GitHub registers the link but does not always close — cause unknown, see `agent/lessons.md`).
  8. Update memory (`lab-state`) and tell Tomas: PR link, merge commit, issue state.
- [ ] **Step 2: Test** — frontmatter parses (first line `---`, `name: ship`); every fenced bash block passes `bash -n`:
```bash

```
