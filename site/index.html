How these are built

Every project lives in its own repository and starts from the same base: the data-engineering-lab repository, which holds the rules all of them follow (conventions, security and cost guardrails, decision records), the project template, and the operating manual of the AI teammate — Claude Code — that designs, builds and explains each one with me.
